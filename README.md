# Бот «Швейная терминология: ВТО и машинные операции»

Telegram-бот для изучения глаголов влажно-тепловой обработки (ВТО) и
машинного шитья через текстовые карточки с интервальным повторением
и викторину.

## Возможности

- 📖 **Карточки** — повторение по алгоритму Leitner (интервалы растут:
  сейчас → 1 → 3 → 7 → 14 дней). «Запомнил» двигает карточку вперёд,
  «Повторить» возвращает в начало.
- 🎯 **Викторина** — по определению и контрастная пара (различить
  запутывающие термины).
- 🔔 **Напоминания** — бот сам присылает вопрос пару раз в день.
- 📊 **Прогресс** — выученные слова, серия дней подряд, счётчик ответов.

В базе ~34 термина:
- **Операции ВТО:** утюжить, отутюжить, заутюжить, разутьюжить, сутюжить,
  оттянуть, отпарить, декатировать и др.
- **Машинные операции:** стачать, втачать, притачать, обтачать, настрочить,
  пристрочить, отстрочить, застрочить, расстрочить, выстегать, простегать.
- **Ручные (временные) работы:** сметать, наметать, вметать, заметать,
  выметать, приметать.
- **Детали и линии кроя:** втачной рукав, глухая застёжка, ампирная линия,
  лацкан, подборт.

## Запуск на Windows (простыми словами)

Чтобы бот работал, нужно **4 шага**. Команды вставляй в «Командную строку» —
открой её через «Пуск» → набери `cmd` → Enter.

> Нужен установленный **Python 3.10 или новее**.
> Проверить: в командной строке набери `python --version`.

### Шаг 1. Скачать проект
```bat
git clone https://github.com/shchukinsergey/vto_test.git
cd vto_test
```

### Шаг 2. Вставить токен бота
```bat
copy .env.example .env
```
Открой файл `.env` (блокнотом: `notepad .env`) и замени `BOT_TOKEN=...` на свой
токен. Как получить токен: в Telegram напишите **@BotFather** → `/newbot` → имя
бота → скопируйте токен. Можно взять тот же, что уже используется.

> ВАЖНО: бот на одном токене — один. Если он уже запущен на другом компьютере,
> здесь не запускай одновременно.

### Шаг 3. Поставить зависимости (один раз)
```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```
Скачает всё нужное для бота. Делается один раз.

### Шаг 4. Создать базу и запустить бота
```bat
.venv\Scripts\python scripts\seed_db.py
.venv\Scripts\python -m bot
```
Первая команда создаёт базу с терминами (один раз). Вторая — запускает бота.
После неё в Telegram отправь боту `/start` — появится меню.

**Остановить бота** — нажми `Ctrl` + `C` в этом окне. Пока окно открыто, бот
работает; закроешь окно — бот остановится.

### Если всё сразу (одним набором)

Вставляй по строкам:
```bat
git clone https://github.com/shchukinsergey/vto_test.git
cd vto_test
copy .env.example .env
notepad .env
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python scripts\seed_db.py
.venv\Scripts\python -m bot
```

## Команды и меню

- `/start` — главное меню.
- **Карточки** — повторить карточки, подлежащие повторению (или весь набор).
- **Викторина** — выбор режима и серия вопросов.
- **Прогресс** — статистика.
- **Все термины** — полный список терминов.

## Как добавить термины

Дополните список `TERMS` в `bot/content.py` (глагол, определение, пример,
категория, контрастная группа), затем:
```bash
.venv/bin/python scripts/seed_db.py
```
Новые термины добавятся в существующую базу (существующие не дублируются).

## Тесты

```bash
.venv/bin/python -m pytest
```

## Структура

```
bot/
  __main__.py      # запуск: polling + планировщик
  config.py        # настройки из .env
  content.py       # термины и категории
  db.py            # SQLite (aiosqlite)
  srs.py           # алгоритм Leitner
  quiz.py          # логика викторины
  bot.py           # сборка Dispatcher
  scheduler.py     # ежедневные напоминания
  handlers/        # start, learn, quiz, progress, helpers, keyboards
scripts/
  seed_db.py       # инициализация/обновление БД
tests/             # юнит-тесты
data/              # vto.db (генерируется)
```
